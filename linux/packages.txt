# Arch packages this config expects, beyond what Omarchy already installs.
# Install with:  grep -v '^#' linux/packages.txt | sudo pacman -S --needed -
# (pacman reads every stdin line as a target; it does not skip comments.)
# (install.sh only REPORTS what is missing; it never installs unasked.)

# NOTE: zsh is deliberately NOT here. This machine runs Omarchy's default bash
# everywhere -- see docs/shell-decision.md. The Mac keeps zsh.

direnv
fzf

# claude/setup.sh merges ~/.claude/settings.json with it.
jq

# Wayland clipboard, the pbcopy/pbpaste equivalent.
wl-clipboard

# 4x6 thermal label printer (Yxwl/Labeer Y812BT) over USB -- see

# author, and it carries TSPL/ZPL/EPL/DYMO drivers -- so no vendor .run blob

# already (this file is only for what it does not), and the Canon PIXMA needs
# nothing beyond them -- it is driverless IPP Everywhere, no Canon package.
lprint
